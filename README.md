# Apex Agent ⚡

> Autonomous Personal Searchable Memory Agent for Solo Founders & Power Users.
> Built for the "AI for Everyday Life - The Memory Agent" Hackathon.

## Core Capabilities
1. **Cross-Data Ingestion**: Seamless ingestion across WhatsApp chats, PDFs, .eml emails, and Markdown notes.
2. **Context & Relationships**: Entity graph mapping People, Events, Organizations, and Documents.
3. **Conflict Detection**: Detects contradicting sources and highlights disagreements without guessing.
4. **Source Attribution**: Strict provenance tracking on every recalled memory chunk.
5. **Anti-Hallucination**: Grounded retrieval + strict context fencing + uncertainty scoring.
6. **Autonomous Operations (Bonus)**: Proactive cron-based morning briefings and pipeline watchdogs over Telegram.
